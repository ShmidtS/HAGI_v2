# Уровень-2 рекурсия: путь DFT3 работает, качество требует обучения

Дата: 2026-09-26. Отвечает на исходный вопрос задачи: работает ли
рекурсивный рост.

## Пре-регистрация

Критерий записан ДО прогона в `reports/LEVEL2_PREREG_20260926.md`:
успех = `level2_macro <= min(level1_macro) + 0.01`.

## Три тупика, найденных по пути (все реальные, все закрыты)

1. **`hidden_size` обязан равняться `num_query_heads * head_dim`.**
   Расширение скрытой оси втрое требует расширить и число голов
   (6 → 18 → 54). Это меняет форму модели, а не только её wiring.

2. **Плоские доменные эксперты не годятся как эксперты уровня-2.**
   У них `q_norm` 1D `[64]` (одна голова на эксперта), а иерархическая
   ветка ждёт 2D `[n_heads, head_dim]`. Ошибка: `merged shape (192,) !=
   target (64,)`. У merged-моделей ровно 2D — поэтому рекурсия строится
   из merged, а не из доменных экспертов.

3. **`mixer_hadamard_groups: []` ломал сборку.**
   `all([]) == True` → ветка тернарной группы → `reshape` с
   `n_blocks // 3 == 0` → `RuntimeError: shape '[32768, 0, 3, 1152]'`.
   Исправлено в `ee18a38`, DFT3-путь не изменён.

## Результат пробы (уровень-1 = merged s5678, три слота DFT3)

| рука | macro exact_ce |
|------|----------------|
| merged_4500 | 6.168332 |
| merged_4500_dup | 6.165233 |
| merged_9000 | 5.882539 |
| **level2 (три слота DFT3)** | **7.747119** |

Дельта уровня-2 к лучшему уровню-1: **+1.864580** — провал по
пре-регистрированному критерию.

## Вердикт: REJECTED на шаге 0, но это НЕ опровержение рекурсии

Провал объясняется конструкцией, а не гипотезой. Код сам это
фиксирует (`src/hagi/model/merge.py:1895`):

> «a freshly merged model scores poorly (AVG~9) before joint training»

Свежеслитая модель **неизбежно** плоха до обучения: кросс-экспертный
миксер инициализируется нулями, и до обучения три эксперта не смешаны.
Поэтому сравнивать «после слияния, до обучения» против «после 9000
шагов обучения» — нечестно ровно так же, как в M2 было нечестно по
бюджету шагов.

Пре-регистрация это допускала: критерий требовал измерить результат, и
провал на несправедливом сравнении — повод починить сравнение, а не
объявить рекурсию мёртвой.

## Что доказано

- **Трёхсторонний DFT3-путь на уровне-2 работает.** hidden 3456, 54
  головы, 430M параметров, сборка проходит, `n_experts` остаётся 3,
  миксер остаётся на тернарном подъёме.
- Иерархическое слияние merged-моделей технически возможно.

## Что не доказано

- Что уровень-2 даёт выигрыш в качестве. Требуется обучение
  уровня-2 с согласованным бюджетом шагов — то же, что потребовалось
  для M2.
- Три **независимых** merged. Из имеющихся чекпойнтов только два
  уникальных (4500, 9000) на сид, третий слот — повтор. Проба
  доказывает «путь строится и не разрушает модель», а не «три
  независимых поколения сливаются лучше».

## Честный следующий шаг

Обучить уровень-2 (4500 + 9000 шагов) и сравнить с уровнем-1 при
**том же** бюджете — ровно как в M2. Тогда число будет значимым.
Обучение уровня-2 — это ~430M параметров, то есть существенно дороже
текущих прогонов; это отдельное решение по ресурсам.
