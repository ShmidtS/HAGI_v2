## QP-решатель (SafeQP.lean → formal.py)

`safe_qp_multipliers(G, b, eps)`: двойственная форма d* = g + Σλᵢgᵢ,
λ* = argmin_{λ≥0} ½λᵀGλ + λᵀ(b+ε); активное множество перебором
(K≤8 → ≤256 подмножеств). Верифицировано: невидимость без конфликтов
(b≥0 → λ=0), ограничения держатся, спуск гарантирован
(⟨g,d*⟩ ≥ ‖d*‖²), ‖g−d*‖ ≤ ‖g‖, ε-бюджет смягчает.
