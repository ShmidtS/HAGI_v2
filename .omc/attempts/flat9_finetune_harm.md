# flat9 fine-tune: post-merge обучение ВРЕДИТ (BAR-протокол не переносится)

## Что делали

BAR (Ai2, 2604.18473) показал: после merge экспертов router-only
training (lr 1e-4, 5% данных, 2 эпохи, всё кроме роутера заморожено)
улучшает собранную модель. Перенесли протокол на flat9 (9 leafv3,
init-ансамбль CE 4.4445, старт mixer_init_scale=0):

- ft_m1: freeze_experts, только mixers, lr 1e-3, 400 шагов
- ft_u1: полный unfreeze, lr 1e-3, 400 шагов

## Результаты (hold-out ru, sweep scale)

| модель | CE |
|---|---|
| **flat9 init (бесплатный ансамбль)** | **4.4445** |
| явный 1/n ансамбль листьев | 4.4333 |
| ft_m1 step 200 | 4.9000 |
| ft_u1 step 200 | 5.1908 |
| ft_m1 step 400 | 4.8314 |
| ft_u1 step 400 | 4.8287 (scale ушёл 0.115→0.151, sweep это НЕ объясняет) |

**Обе руки хуже init на +0.39 ната. Sweep logit_scale не спасает
(оптимум при родной температуре). Fine-tune вредит на любом шаге.**

## Causal-декомпозиция (Concat.lean A2, выполнена)

явный 1/n ансамбль = 4.4333; merged (до joint) = 4.4445.
**Композиционный вклад слияния = −0.011 ната (шум bf16/архитектуры).
Весь merge-эффект −0.21 ната — чисто АНСАМБЛЕВЫЙ.** Конкатенация
блоков не добавляет информации сверх усреднения логитов — это важно
для понимания: concat даёт capacity (9× параметров), но качество
на init — свойство среднего, не структуры.

## Почему BAR-протокол не переносится (гипотезы)

1. BAR-эксперты — DIVERGED (разные домены: math/code/tools); router
   выбирает ИНФОРМАТИВНОГО эксперта. Наши leafv3 — 9 рейнов одного
   распределения (разные seed); среднее уже оптимально, миксер может
   только добавить шум. **Concat 9 одинаковых листьев — вырожденный
   MoE: роутить нечего.**
2. lr 1e-3 для 400 шагов слишком высок (BAR: 1e-4 на 2 эпохах 5%
   данных ≈ куда меньше обновлений на параметр). u1 дрейф温度
   (scale 0.115→0.151) — признак слишком агрессивного lr.

## Следствия для программы

- Механика роста flat concat на ОДНОРОДНЫХ листьях НЕ нуждается в
  post-merge обучении: init-ансамбль — лучшая точка. Рост = добавление
  листьев, каждый из которых обучается отдельно, сборка бесплатна.
- Если листья ДИВЕРСИФИЦИРОВАНЫ (домены), миксер может стать
  полезным — это BTM/BAR-ветка (не проверено на нашем стенде).
- «Train only the mixer» на однородных листьях — анти-паттерн.
- u1 (unfreeze) тоже вредит: even joint training не окупается при
  коротких прогонах — модель теряет больше от смещения с init-точки
  (ансамбль уже близок к bayes-optimal для этого набора листьев),
  чем находит нового.

## Вердикт

flat9 итог: CE 4.4445 (бесплатный ансамбль) — принимать без
fine-tune. Это и есть механика роста: следующий уровень лестницы
собирается из flat9-подобных блоков... НО: flat9 из 9 однородных
листьев ≈ один лист с 9× весами и усреднёнными предсказаниями;
уровень 2 должен строиться из ДРУГИХ листьев (иные домены/срезы),
иначе ансамблевый выигрыш уже исчерпан (mean-of-9-seeds ≈ mean of
any 9 iid samples, добавление новых seed-листьев сходит на нет —
закон больших чисел).
