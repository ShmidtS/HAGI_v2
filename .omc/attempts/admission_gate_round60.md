# Round 60: T1a admission-гейт применён — сертификаты зазора для трёх пулов

## Замер (8 канонических окон, 0 GPU, Wave-10 T1a)

| пул | эмпирический Jensen-gap | M = mean max|Δz| | сертификат ≤ ½log cosh M |
|---|---|---|---|
| 3× seed | 0.0160 | 2.58 | 0.9448 |
| 3× boost | 0.0212 | 3.09 | 1.2004 |
| 2 seed + boost | **0.0746** | 6.61 | 2.9587 |

## Выводы

1. **Гейп-иерархия**: seed < boost < mixed (0.016 / 0.021 / 0.075).
   Смешанный пул (меж-источниковая diversity) имеет 4.7× зазор
   seed-пула — наибольший admission-потенциал по T1a.
2. Сертификат cosh-M работает (верхняя граница с запасом ~45×,
   ожидаемо: max-норма груба для среднего зазора) — дешёвый
   admission-инструмент: candidate допускается iff ½log cosh M > ε.
3. Противоречие с round-56 ансамбль-CE (mixed 3.5783 > pure-boost
   3.5650): mixed пул имеет больший ПОТЕНЦИАЛ (gap), но худшую базу
   (CE(mean) выше) — GapLaw: итог = CE(mean) − gap. Growth-supervisor
   должен смотреть ОБА числа: admission по gap-сертификату И базу
   по solo. Точная иллюстрация Select.lean (standalone ≠ вклад).

## Процессуальное

T1a-гейт (M по одному проходу, 0 GPU) теперь обязательный
пре-фильтр кандидатов в ансамбль/merge перед любым GPU-циклом.
