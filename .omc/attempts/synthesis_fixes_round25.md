# Раунд 25: исправления синтеза — O(V)-gap, κ-rank, Fisher-скоринг, speed-фиксы

## Математические фиксы (синтез-раунд, все верифицированы)

1. **twoGap O(V²) → O(V)**: факторизация двойной cosh-суммы
   Σ p_u p_v cosh(d_u−d_v) = (Σ p_u e^{d_u})(Σ p_v e^{−d_v}) — точная,
   без приближения. `two_gap_fast` в formal.py; проверена ≡ прямой
   cosh-сумме ≡ lse-форме (совпадение до float32-шума). Online-
   scoring большого пула экспертов теперь дёшев.

2. **κ-множитель в RankBudget** (баг синтеза поймал): оптимальный
   ранг r_j* = (log c_j + log κ_j − log λ − log(m_j+n_j))/κ_j,
   активное множество c_j κ_j > λ(m_j+n_j). `rank_budget_allocation`
   (binary-search λ, активное множество, бюджет-инвариант).

3. **Fisher/Jensen-скоринг отбора**: S_i = δᵀFδ (F = diag(p)−ppᵀ —
   гессиан softmax в среднем) — «новая информация» кандидата,
   взвешенная чувствительностью выхода; лучше прокси 1−ρ (не
   выбрасывает масштаб). `fisher_novelty`; проверен порядок
   (независимая δ > дублирующая).

## Измерение LoRA-B (проверка гипотезы RankBudget)

Спектр B-строк РАВНОМЕРЕН (0.54–0.63, все 16 направлений активны) —
**ранг-16 не насыщен**: все направления несут специализацию с равной
энергией. Измеренное предписание: r=16 не избыточен; r-sweep (r=32,
48) обещает выигрыш. Экспоненциальный хвост для E_j(r) по этому
замеру проверить нельзя напрямую (ранг мал) — RankBudget условен до
r-sweep'а; замер column-energy max/mean=2.2 говорит о мягкой
анизотропии.

## Speed-фиксы (синтез §9, §5)

- **grad_checkpointing off** для всех gen-циклов (7 конфигов
  пропатчены): замерен эффект 172→161 ms/step (~6.4%) на H=384
  joint. Мелкие прогоны не должны платить recompute.
- **Head без материализации V×H** (§6): X(W₀+AB)ᵀ = XW₀ᵀ + (XB)Aᵀ —
  O(NHr+NVr) без дельта-таблицы. Верифицировано ≡ материализованный
  путь (7.6e-6). .weight-property сохранён для generation/merge
  путей; прямой путь — новый forward().

## Очередь (по синтезу)

1. Fisher-скоринг в growth_gate (заменить 1−ρ в финалист-стадии).
2. Gen-3 цикл (предсказание Compound.lean: M₃ = M₂ − (αG₂+J₂),
   фальсификация до GPU).
3. Local+sinks без T²-mask (§8, O(T(W+S))) — перед любыми
   attention-экспериментами.
4. NCE variance-теорема + adaptive-K (§7/§9).
5. Input-preconditioned Muon (диаг. аппроксимация, §11).
6. Двухканальная регрессия c_t на (G_t, J_t) — 2 цикла данных
   уже есть (compound_constant_regime проверка).
