# Раунд 30: NCEExact-вердикт подтверждён числом + anchor-эксперименты (отрицательный результат)

## K_eff-диагностика (теорема → число)

С одного forward на fused-листе (well-calibrated): K_eff = K·Z²/(Σe^{2z}/q) =
**32.1 при K=2048** — unigram proposal плохо покрывает peaked-модель
(эффективная выборка в 64× меньше номинала). Но delta-потолок шума =
(1/2K)·E[W²]/Z² = **0.016 ната << 47**. Вердикт теоремы подтверждён
числом: 47 ната — НЕ sampling-noise, а неограниченная динамика вне
сэмпла. Практическое следствие: для шумовой границы хватит K≈100–300;
главное — anchor, не K.

## Anchor-пакет (реализован в train loop)

`train.nce_anchor_weight` + anchor-градиент в objective (exact-CE на
exact_ce_rows позициях каждые exact_ce_interval шагов, ДО основного
backward — один graph). Плюс z_loss 0.01, logit_scale_max.

## Диагноз остаточного разрыва (scale-sweep)

Scale 0.2 (почти чистый prior): edu CE **6.17** — ЛУЧШЕ обученного
scale 1.76 (9.2). NCE-объектив выучивает условную поправку, которая
ВРЕДИТ на полном partition: между anchor-точками поправка растёт до
вредной амплитуды, anchor возвращает, но не полностью. Scale-clamp не
лечит (поле поправки само по себе кривое).

## ЧЕСТНЫЙ ВЕРДИКТ ПО NCE

Sampled prior-NCE при V=32k **не достигает fused-качества** на этом
масштабе данных/модели ни с одним anchor-вариантом: 11.4 против 5.95
— потеря 5.5 ната против 4× шага. Для leaf (V мал, fused_ce уже
эффективен) — NCE НЕ рекомендуется; его место — V≥256k+ (1B-конфиг),
где O(NVH) действительно доминирует. Вывод согласован с Lean: теорема
сказала «шум не объясняет», но лечение anchor'ом недостаточно —
структурная разница objectives остаётся.
