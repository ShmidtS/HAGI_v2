# SOTA-аудит (DeepSeek V4.1-Flash, Kimi K2): перенос на лист

## Разобрано

- **DeepSeek V4.1-Flash** (2609.19969 + kgptalkie teardown): CSA2 —
  lightning indexer (32 FP4-головы), pick 512 + окно 128, reuse-режимы
  (8 из 40 слоёв гоняют индексер), асимметричный enc-dec (20+20),
  KV-кэш 890 байт/токен (437× меньше V1). Арифметика: скаут в 6.8×
  дешевле полномасштабного скора, весь блок — 158× дешевле dense.
- **Kimi K2** (2507.20534, theorempath breakdown): MuonClip = Muon +
  QK-Clip (per-head пост-апдейтный клип q/k-проекций при S_max > 100);
  sparsity-48 MoE; halved heads; WRAP-rephrasing данных (+5 п. SimpleQA).

## Перенос на лист H=128 (честная фильтрация по масштабу)

| приём | вердикт | причина |
|---|---|---|
| CSA2 indexer | нет | seq 1024: индексер — чистый оверхед (K2-логика: скаут окупается с 64K+) |
| MLA latent KV | нет | GQA 2:1 + sink уже мал; кэш не боттлнек |
| enc-dec асимметрия | нет | трюк 1M-контекста |
| halving heads | уже | 2 головы = минимум |
| WRAP-rephrasing | backlog | ось данных, дорогая (нужен внешний LLM-рерайтер) |
| **QK-Clip (MuonClip)** | **проверено измерением: НЕ НУЖЕН** | см. ниже |

## QK-Clip аудит (единственный дешёвый перенос)

K2 задокументировала: Muon на 9B-модели загоняет max attention logit
>1000 за 1000 шагов → лосс-спайки; фикс — QK-Clip. Наш Muon (раунд 6)
принят без этого гварда — обязательная проверка.

**Замер** (leafv3 s2001, Muon, 800 шагов, hook на `_sdpa` входах,
реальный текст): max-логиты по слоям = 10.6 / 11.1 / 11.3.

**Вердикт: логиты ограничены (~11 против порога 100), qk_norm +
centering (Fix A) полностью держат рост. QK-Clip не нужен на масштабе
листа.** Muon-гвард — уже реализованная защита (qk_norm: true в
каноне), отчёт закрывает вопрос.

## Вывод

SOTA-аудит листа ЗАКРЫТ: архитектура листа уже содержит все приёмы,
которые окупаются на масштабе 8.7M/seq1024 (qk_norm+centering, Muon,
zero-init, tuned theta, GQA). Крупные SOTA-трюки (CSA2, MLA, enc-dec)
окупаются с 64K-1M контекста — наш масштаб на 2-3 порядка ниже их
зоны применимости. Проверяемых осей от V4.1/K2 на листе не осталось.
