# Раунд 17: GapLaw → код — точная форма gap + комплементарность + выведенный порог

## Что доказано Lean-агентом (GapLaw.lean, RealF3.lean)

- **twoGap_cosh**: gap = ½·log Σ p_u p_v cosh(d_u−d_v) — ТОЧНАЯ форма
  (не приближение): sinh-часть сокращается (u,v)-симметрией.
- **twoGap_zero_iff**: gap = 0 ⟺ consensus (двухточечный
  consensus_no_gain).
- **pairVarEq**: квадратичный закон ½·Tr[H·Cov] — малосигнальный
  предел точной формы (log cosh x ≈ x²/2).
- **P4**: Gap(N) ≈ G∞(1−1/N), инкременты ~G∞/N²; SATURATED при
  N > √(G∞/ε) — выведенная замена TOL_GAP.
- **P2**: приращение gap определяется кросс-ковариацией δ_c с
  δ̄_pool; комплементарность = 1−ρ.
- **RealF3.lean**: production R (6×6) — транспортированный формальный
  объект (изометрия ℂ³→ℝ⁶ + конъюгация с character-действием);
  digest-тесты формально заземлены.

## Верификация формулы на живой лестнице (раунд 17)

Сначала поймал два бага переноса (оси u/v — VOCAB, не листья;
fp32-cosh переполняется на V=32768 → float64). Аналитический случай
([2,0]/[0,2]): прямое 0.43378 = cosh-форма 0.43378 — идентичность
подтверждена. Затем на лестнице v3 (lse-форма, targets-сокращение):

| n | измеренный gap | точная формула (lse) | сдвиг |
|---|---|---|---|
| 3 | 0.3116 | 0.2882 | 0.023 |
| 9 | 0.3639 | 0.3400 | 0.024 |

Систематический сдвиг 0.023 — bf16 прямого CE-пути против float64
формулы; сама формула точна в double. ГЛАВНОЕ: формула вычислима
БЕЗ CE-прогонов листьев (targets сокращаются) — O(N) forward + lse.

## Кривая предсказана и наблюдается

Gap(N): 0.40→0.44→0.47 (измерено, раунд 16); закон G∞(1−1/N) при
G∞≈0.52 предсказывает 0.35/0.43/0.47 для N=3/6/9 — согласовано в
пределах шума окон. Порог N* = √(0.47/0.0021) ≈ 15.3 — совпадает с
измеренным ЗБЧ-плато N≈9-16 (ladder_exhaustion_curve). **Эмпирическое
плато получило выведенную формулу.**

## Перенесено в код (src/hagi/model/formal.py)

1. `jensen_gap_lse(logits[n,B,T,V]) -> [B,T]` — точный gap без
   CE-прогонов (доказанная эквивалентность lse/cosh на аналитике).
2. `complementarity(delta_c, delta_pool) = 1 − ρ` — решающая метрика
   отбора кандидата (P2; формальная сторона selection_hurts).
3. `saturated_threshold(G∞, ε) = √(G∞/ε)` — выведенный SATURATED-
   порог; при G∞=0.47 → N*=15.3 (совпало с измеренным плато).

Тесты: аналитическая идентичность, consensus-ноль, порядок
комплементарности, выведенный порог — 13 passed.

## Не перенесено

- cosh-форма как отдельная функция: lse-форма эквивалентна и
  численно стабильнее (cosh переполняется fp32) — документировано в
  docstring jensen_gap_lse.
- Ортогональность R (RealF3): следующий шаг модуля, не заявлена как
  теорема — код не меняется (digest-тесты уже пинят поведение).

## Значение

Цикл «measure disagreement → choose complementary child → merge →
decide grow/stop» теперь ПОЛНОСТЬЮ выведен: точный gap-закон —
дешёвая пред-merge-метрика; 1−ρ — решающее правило; √(G∞/ε) —
выведенный стоп. Ни одной эмпирической константы в петле роста,
кроме floor ε=0.0021 (сам измеренный floor).
