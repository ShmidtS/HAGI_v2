# Round 34 (продолжение): equal-compute scratch-контроль ЗАКРЫТ — рост бьёт нуль на 0.9985 ната

## Scratch-сага: root cause цепочки провалов (честно, с нарушением дисциплины)

Первые 5 попыток scratch H=384 падали с inf-градиентами (step 2–315).
Процессуальное нарушение признано: shotgun-перезапуски вместо стопа после
3 неудач. Диагностика, проведённая в итоге системно:

1. **torch.compile на fresh H=384 даёт inf-градиенты 10/10 шагов**
   (eager 0/10) — компиляторный баг на новой форме головы (hipblasLt
   fallback-варнинги на тех же GEMM). Scratch-руки обязаны compile off.
2. **fused_ce=True + z_loss=1e-3 на fresh H=384 — расходящаяся
   динамика logit_scale**: градиент скейла растёт −0.008 → −2.4 за 5
   шагов; Adam-шаг фиксированного размера двигает scale вверх ~0.001/шаг
   до bf16-переполнения на шаге ~70–315. Все эпохи-2 руки наследовали
   обученный scale (0.68–2.2) и никогда не входили в этот режим.
3. **Рабочий рецепт — точный era-1 fresh-arm** (flat9/parent-руки):
   `fused_ce: false, z_loss: 1e-4, use_muon: false, lr: 1e-3` —
   1600 шагов, 0 non-finite, CE 10.39 → 4.69 (min) → 5.05 (финал).

Код-фиксы по итогам (оба легитимны независимо от scratch):
- `logit_scale_max` enforcement в `HybridOptimizer.step()` — конфиг-ключ
  существовал с самого начала, но никогда не применялся (мёртвый хвост,
  класс бага merge.n_mixers round-24). Кламп после optimizer-шага.
- `growth_verdict()` + `mechanism_marginal_value()` в formal.py — перенос
  Lean-34 (growth_verdict_table + ComputeBudget в free-energy валюте).
  Живая калибровка: dbridge pre-joint скан → GROW (исход подтвердился,
  Δ_joint=0.35); gen-3 post-revival → TTT/LORA.
