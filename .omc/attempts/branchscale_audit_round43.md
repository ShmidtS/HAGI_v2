# Round 43: BranchScale-аудит — 5/7 скейлов заперты нижней границей clamp

## Lean wave-5 перенос (branchscale_minmax)

Теорема: при Σs_l² = B максимум max_l s_l²·v_l ≥ B/Σ(1/v_l),
равенство при равномерности; единый скейл доказуемо субоптимален.
Предписание: per-layer скейлы обязаны компенсировать измеренную v_l.

## ВЕРДИКТ и предписание

Clamp [r/2, 2r] — активное ограничение, запрещающее Lean-оптимальную
компенсацию. Следующий A/B (по рецепту round-2 + Lean):

  рука A: branch_clamp_ratio = 2 (текущий)
  рука B: branch_clamp_ratio = 8 (или s₀=1, clamp 8)

на gen2-merged→joint, 3 seed. Ожидание (слепой прогноз): B ≥ A на
величину порядка разброса вкладов ветвей; худший случай — паритет
(скейлы не успевают уйти за 1600 шагов — тогда lr для BranchScale
отдельный).
