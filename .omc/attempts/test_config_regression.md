## Кривая исчерпания лестницы (главный результат раунда)

flat N ∈ {3, 9, 16} однородных leafv3, hold-out ru, τ=0.0042:

| N | CE | ambiguous ε=0.0021 |
|---|---|---|
| 1 (лист) | 4.6578 | — |
| 3 | 4.4923 | 5.6% |
| 9 | 4.4445 | 4.9% |
| 16 | 4.4152 | 5.0% |

**Прирост 9→16 (7 листьев) = −0.029 ната против 3→9 (6 листьев)
−0.048: ЗБЧ-сходимость. Неоднозначность перестала падать после N=9 —
систематический остаток ~5%, который новые копии распределения не
решают.**

Триггер роста откалиброван: рост однородных листьев плато на N≈9-16.
Следующий лист обязан быть иного распределения — но домены без
роутера проигрывают (domain_divergence.md), значит либо (а) роутер
(mixers fine-tune на дивергентных, BAR-протокол, не проверено),
либо (б) иные данные того же языка (не домены: другие источники
ru-текста).

## Механика саморазвития — финальная формула сессии

1. Лист: leaf_h128_v2 (CE 4.85/278с, 9 раундов оптимизации).
2. Сборка: flat-N init-ансамбль, БЕЗ fine-tune (вредит, измерено).
3. Триггер: τ-метрика (выведена из floor, не магия); падение
   ambiguous → расти числом; стоящая ambiguous → менять тип данных.
4. Плато N≈9-16 достигнуто — однородный рост исчерпан, требуется
   следующий тип разнообразия.
