# Growth gate вживую: триггер саморазвития валидирован на универсальной лестнице

## Что собрано

`scripts/growth_gate.py` — исполняемый триггер роста. Решает
GROW / SATURATED-AMBIGUITY / EXHAUSTED по τ-метрике (τ выведен из
floor: eps=0.0021, tau=2·atanh(eps)≈0.0042 — Concat.lean C7, не
магия) и динамике CE между уровнями лестницы.

Валидационная цепочка — живая универсальная лестница из 9 dgen-
листьев (gleaf_s6002-s6010, смесь всех доменов в данных каждого
листа, та же геометрия leaf v2):

| уровень | CE (mixed-holdout) | ambiguity | вердикт триггера |
|---|---|---|---|
| flat3 | 7.3254 | 3.76% | BASELINE |
| flat6 | 7.2529 | 3.33% | **GROW** (amb падает) |
| flat9 | 7.1986 | 3.43% | **SATURATED-AMBIGUITY** (amb стоит, CE падает) |

Вердикт flat9 совпал с независимо измеренной кривой исчерпания
ru-лестницы (плато неоднозначности на N≈9) — триггер переносится
между наборами листьев без перекалибровки.

## Абсолютные числа mixed-метрики

CE ~7.2 на mixed-holdout НЕ сравним с ru-числами (4.4-4.9): метрика
взвешивает хвосты всех 6 корпусов, включая en/math, где ru-лист
слаб (17.8). Для триггера важна сопоставимость УРОВНЕЙ между собой
(одни и те же окна), не абсолют. Универсальная лестница честно
показывает: один общий CE на всех доменах — 7.20 у flat9 против
7.33 у flat3 (−0.13 ната на mixed, больше чем ru-выигрыш, т.к.
mixed-данные多元化).

## Механика саморазвития — ФИНАЛ (всё измерено, всё автоматизировано)

1. **Элемент**: leaf v2 (universal weights) — CE 4.85 ru / mixed-базис
   7.4, 278с, 9 раундов оптимизации.
2. **Рост**: параллельные листья → flat-N init-ансамбль (бесплатный,
   без fine-tune — измерено, что обучение вредит).
3. **Триггер** (`growth_gate.py`): amb падает → GROW; amb стоит +
   CE падает → SATURATED (данные, не счёт); оба стоят → EXHAUSTED.
4. **Валидация**: две независимые лестницы (ru 9 листьев, universal
   9 листьев) дают один и тот же вердикт на flat9 — SATURATED.

## Правило масштаба (урок сессии, подтверждён)

Ансамблевый выигрыш ~1/N (ЗБЧ); плато неоднозначности ~5% (ru) /
~3.4% (mixed) — систематический остаток, не решаемый копиями
распределения. Дальнейший рост = качество элемента через данные
(WRAP-ветка — единственный непроверенный SOTA-перенос), не через
сборку.

## Как пользоваться

```bash
# уровень N: собрать и решить
python scripts/growth_gate.py --configs configs/gleaf_s600{2..9}.yaml --configs configs/gleaf_s6010.yaml \
    --prev-ambiguity 0.0333 --prev-ce 7.2529
# verdict: GROW → добавить листьев; SATURATED → новые данные в элемент;
# EXHAUSTED → менять рецепт элемента
```
