## Из поиска (для следующих итераций, не применено)

- Critical Batch Size (Ai2 2025): наш batch 8×1024×4accum = 32k токенов/шаг
  — для листа 8.7M это, вероятно, ниже CBS; batch warmup с √B lr-scaling —
  кандидат, но требует замера времени/качества.
- Small-batch work (arXiv 2507.07101): «batch size one наравне с большим
  при равных токенах» — наш grad_accum 4 может быть лишним для скорости
  (кандидат на замер: accum 1 vs 4 по времени).
- β2 token half-life (aditsom): при смене batch/accum пересчитывать
  β2, держать half-life в токенах — у нас β2=0.95 фиксирован.
