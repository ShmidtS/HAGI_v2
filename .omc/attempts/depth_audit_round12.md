# Depth-аудит: 2502.10858 (breadth-vs-depth) против наших замеров

## Статья (UESTC/SUTD, «Is Depth All You Need?»)

Deep iterative reasoning активирует предобученные знания итерациями.
Breadth (разнообразие путей) может заменить depth, НО (finding ii)
self-consistency с ограниченной диверсификацией НЕ заменяет depth
целиком. Импликация для нас: breadth с seed-only диверсификацией
(наша лестница) оставляет за depth некоторый вклад.

## Наши замеры (все — mixed W=10, 8 корпусов)

| режим | CE |
|---|---|
| flat9 v3, depth 1× (базис) | **6.0598** |
| flat9 v3, depth 2× на инференсе (вес ld1) | 6.3129 (вредит) |
| flat9 v3, depth 3× на инференсе | 6.7126 (вредит) |
| ld2-v3 ОБУЧЕННЫЙ (1600ш, 8 корп, native d2) | 6.4558 |
| ld1-v3 листья, среднее (9 seed) | 6.44 |
| ld2-v3 elastic d1 (50% compute) | 7.9221 |

## Вердикт

1. **Обученная depth (ld2, новый рецепт) = ld1 в пределах шума**
   (6.46 vs 6.44) при 2× compute на шаг. Прежний ld-вердикт
   подтверждён и на каноне v3.
2. Depth на инференсе без переобучения — монотонный вред.
3. Elastic-разрыв у обученного ld2 вырос (6.46 vs 7.92): обученная
   траектория НУЖДИТСЯ в обеих итерациях — дешёвого инференса нет
   без shortcut-обучения (LoopFormer-фикс).

## Синтез двух статей и наших данных

- Breadth-ансамбль (наша лестница) — единственная форма, которая
  платит на нашем масштабе (−0.38..−0.44 ната).
- Depth платит в двух режимах, ОБА требуют условий, которых у нас
  нет: (а) reasoning-задачи + большая база знаний (o1-режим,
  статья 2502.10858), (б) shortcut-consistency обучение петли
  (LoopFormer). На LM-цели ppl>6 обе статьи и наши замеры
  согласны: depth не даёт.
- Граница честная: если HAGI дорастёт до reasoning-уровня (данные!),
  depth-ветка (ld2 + LoopFormer-рецепт) — первый кандидат на
  включение; сейчас — YAGNI.

## Дополнение

Статья 2502.10858 также подтверждаетbreadth-принцип лестницы:
диверсификация путей > итеративное уточнение, при условии, что
диверсификация РЕАЛЬНА (контекст, не только сэмпл-шум). Это ровно
наш вердикт раунда 10: разнообразие ДАННЫХ (корпуса) бьёт
разнообразие seed. Два независимых подтверждения одного принципа.
