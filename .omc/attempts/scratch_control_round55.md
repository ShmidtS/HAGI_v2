# Round 55: compute-matched scratch — growth выигрывает 0.68 nat при равном бюджете

## Дизайн (закрывает возражение ревью round-6 п.1)

- scratch H=384, 3 слоя, ТОТ же оптимизер/рецепт что листья
  (Muon+AdamW, тот же LR-schedule/warmup), 3040 шагов ≈ 1.9×
  шагов gen-1 joint (1600) — выравнивание суммарного compute.
- Сравнение: gen-1 joint (merge 3 сибов + 1600 joint шагов) = 3.6357.

## Результат (gate, взвешенный, хвост-окна)

| модель | gate CE |
|---|---|
| **scratch H=384, 1.9× шагов, равный рецепт** | **4.3181** |
| gen-1 joint (рост) | 3.6357 |

**Growth-преимущество: 0.68 ната при равном compute.**

Исторический scratch (4.6342, иной рецепт/шаги) обновлён честным
контролем: даже с идентичным оптимизером и +90% шагов scratch
уступает структурному росту 0.68 ната. Jensen-gap на шаге 0 +
сохранённые представления — не артефакт рецепта.

## Следствие

- Линия «specialize → merge → joint» подтверждена как
  sample-efficient против равнобюджетного flat-обучения;
  headstart_pays_iff (T3d, закрыт формализатором) получает
  второе эмпирическое подтверждение на новом контроле.
