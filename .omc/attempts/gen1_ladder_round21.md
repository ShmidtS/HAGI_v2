# Раунд 21: лестница gen-1 — рекурсия продолжает компаундиться

## Результаты (mixed 8-corpora, gate-протокол)

| ступень | CE | примечание |
|---|---|---|
| v3-independent flat3 | 6.120 | раунд 18 |
| E₀-листья flat3 (shared prior, gen0) | 5.875 | раунд 19 |
| gen1 joint single (merge→fine-tune lr=1e-3) | 5.694 | раунд 20 |
| **gen1 sibling ensemble (N=3, exact algebra)** | **5.6206** | этот раунд |

Полная траектория: −0.50 ната от независимой лестницы, каждый
уровень рекурсии добавляет. Mean single sibling 5.656; Jensen gap
0.036 — мал: общий flat3-prior съел почти весь disagreement
(согласуется с Element.lean: общий компонент дельт ~65-87%).

## Открытия

1. **Иерархический merge физически сломан** (баг найден, не
   исправлен): merge_experts для экспертов-самих-merged-моделей
   неверно собирает attn_norm (2D stack даёт (3,384), целевая
   модель ожидает (9,128)) — ветка ndim==2 для attn_norm ожидает
   плоскую 1D-структуру листа. q_norm (6,64) vs (64,) тоже. Для
   gen-1 обошлось точной logit-алгеброй (merge не нужен для
   измерения; нужен только для физического роста). Fix — DRY-задача
   вместе с раундом-20 находкой (merge-путь из одного места).

2. **slimpajama-деградация gen1 joint**: per-corpus CE показал
   slimpajama 16.8 (против ~5 у других). Fine-tune от flat3-prior
   улучшил 7 из 8 корпусов, но один потерял. Это режим
   специализации-катастрофы на главном корпусе; кандидаты на
   лечение: (а) снизить долю slimpajama в fine-tune, (б) снизить LR
   ещё, (в) mixout/регуляризация к prior. В mean это скрыто
   (slimpajama вес 0.22 в смеси, но модель на нём деградировала
   сильнее всего).

3. Scale-sweep иерархического merge: минимум ~8.8 при scale 0.18 —
   далеко от ожидаемого; это НЕ scale-проблема, а структурный баг
   сборки (п.1).

## Вердикт по саморазвитию

Рекурсивная петля «shared-prior листья → merge → joint → новый
prior» компаундится и измерима end-to-end. Сестринский ансамбль
превзошёл одиночный gen1: рост продолжается даже при малом gap
(0.036 < EPS-порога 0.0021? нет: gap 0.036 — живой; но инкремент
0.073/шаг... по G∞-закону N*=√(0.036/0.0021)≈4.1 — лестница gen-1
насытится при N≈4).

## Очередь

1. ФИКС иерархического merge (баг п.1) — нужен для физического
   роста выше gen-1.
2. slimpajama-лечение (катастрофа специализации).
3. gen-2: sibling-ансамбль как новый prior (требует п.1 или
   distill-back).
4. gate на gen-1 лестнице: N=3 vs N=4 (n_star_model ≈ 4.1).
