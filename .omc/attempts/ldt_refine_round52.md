# Round 52: LDT state-refinement аудит — loop depth без loop-training РАЗРУШИТЕЛЕН

## Контекст

Ревью (lattice-deduction-transformers) предложило ось «loop depth вместо
width»: обученный блок-стек как оператор дедукции, применение K раз с
reinjection (h ← BlockNorm(h₀ + h + Stack(h))) — как в LDT inner loop.
Нулевое обучение, чистое измерение на гейте.

## Результат (гейт, weighted exact CE, идентичные окна)

| K (проходов стека) | gate CE |
|---|---|
| 1 (= stock, рекорд) | **3.3835** |
| 2 (+reinjection) | 4.9131 |
| 3 | 9.0364 |

**Вердикт: рекуррентное применение оператора, обученного на ОДИН проход,
катастрофически вне распределения** (+1.53 ната при K=2). Слепой прогноз
скрипта («большой K=2 выигрыш без loop-обучения удивителен; ожидаем
проигрыш — оператор не идемпотентен-уточняющий вне своего train-time
распределения») — подтверждён количественно.

## Интерпретация (в терминах ревью)

- LDT-принцип «тот же solve loop в train и inference» — НЕ опциональная
  деталь, а необходимое условие: оператор дедукции должен ВИДЕТЬ
  рекуррентные состояния при обучении. HAGI-блоки видели только 1 проход.
- Ось «loop depth» для HAGI остаётся открытой ТОЛЬКО как обучаемая
  (loop_depth>1 в конфиге + тренировка; loop2-листья существуют, но их
  петля = простой повтор без reinjection — отдельный вопрос).
- Reinjection + post-loop BlockNorm реализованы и валидированы
  (K=1 побитово = stock forward) — готовый инструмент для будущего
  loop-обучения: scripts/audits/ldt_state_refine.py.

## Что перенесено из LDT в HAGI-программу

1. [сделано, отрицательно] zero-training state refinement — закрыто
   измерением;
2. [формализация, отправить] AbstractState + MonotoneDeduction
   (P(x)⊑x, идемпотентность, монотонность, U(P(x))≤U(x), конечная
   терминация ≤ rank(x₀)) — Wave-8-кандидат для формализатора;
3. [концепция] contrast-highway как передача ЧАСТИЧНОЙ информации о
   межветочных различиях — переосмысление F3 поверх RootContrast;
4. [концепция] train+infer joint budget: min T_train + λ·T_infer —
   кандидат в ComputeBudget-расширение.
