## ЗАМЕР (главный)

| модель | gate CE |
|---|---|
| **F3 depth-1 дерево** (3 loop2-листа, lift, root-кора, 1600 шагов) | **3.6635** |

| рекорд сессии (gen-2 LoRA) | 3.4240 |

**Вердикт depth-1: дерево проигрывает плоскому +0.028 ната.**

Root_no_leaf_signal-цена (Lean-35b: лист-различия невидимы коре)
измерена числом. ANOVA-гейт (root_share 0.796 = TREE_PROMISING)
предсказывал дешёвый bound; фактическая цена 0.028 — гейт был
качественно прав (мало), но плоский всё же впереди на равных.

Оговорки честности:
- F3-рука на loop2-листьях vs flat-рука на loop1-листьях — не
  идеально чистое A/B (loop2-листья чуть слабее? их solo-CE ~3.91
  на train-миксе против 3.98 loop1 — сопоставимы);
- root-корта обучалась 1600 шагов с fixed-гейтами (не gumbel) —
  гейт-вариант может дать больше;
- depth-2 (parent→grandparent) не tested — цена может сжиматься
  по глубине (инвариант на каждом уровне).

## Решение по росту

Плоская рекурсия (merge→joint→sibs) остаётся чемпионом; F3-ветка
сохраняется как параллельная (глубина-vs-ширина вопрос открыт,
нужен depth-2 тест для настоящего вердикта — следующая сессия).
