# Кривая исчерпания лестницы: flat 3→9→16 (однородные leafv3)

## Замер (hold-out ru, sweep-scale, τ выведен из floor)

| уровень | CE | ambiguous (ε=0.0021) |
|---|---|---|
| лист (базис) | 4.6578 | — |
| flat3 | 4.4923 | 5.6% |
| flat9 | 4.4445 | 4.9% |
| flat16 | 4.4152 | 5.0% |

## Чтение кривой

- CE: 4.658 → 4.492 → 4.444 → 4.415. Прирост: 3→9 (+6 листьев)
  −0.048 ната; 9→16 (+7 листьев) −0.029 ната. **Убывающая отдача
  на глаз — ансамблевый выигрыш сходится по ЗБЧ** (дисперсия ~1/N,
  CE-выигрыш ~1/N), предельная асимптота ≈ 4.38-4.40.
- Неоднозначность (τ-метрика): 5.6% → 4.9% → 5.0% — **не убывает
  после flat9**. Это ключевой сигнал триггера: усреднение убирает
  дисперсию ошибки, но остаточные 5% позиций — систематическая
  неоднозначность (вуали, редкие токены), которую новые копии того же
  распределения НЕ решают.
- Вердикт по триггеру роста: **лестница однородных листьев вышла на
  плато на N≈9-16; сигнал «рост исчерпан» зафиксирован измерением**.
  Дальнейший рост требует другого типа листьев (иные данные/срезы),
  не новых seed.

## Механика саморазвития — рабочая формула (измерена целиком)

1. Тренируем K листьев параллельно ( embarrassingly parallel).
2. Собираем flat-K бесплатно (init-ансамбль, без fine-tune — он вредит).
3. τ-метрика на hold-out решает: ambiguous падает → добавить листьев;
   ambiguous стоит → сменить тип данных листа.
4. Домены без роутера не собираются (измерено); роутер = mixers =
   отдельная ось (обучение вредит на однородных, не проверено на
   дивергентных с малым lr по BAR).

Полный цикл «элемент → сборка → триггер → вердикт» теперь измерен
на каждом шаге с двойным подтверждением.
