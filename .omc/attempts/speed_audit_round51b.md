# Round 51b: speed audit — chunked-CE «оптимизации» дважды дали регресс; узкое место отображено точно

## Профиль реального LoRA-шага [32×1024] (eager, gen2 H=1152, r16)

| компонент | CUDA ms | доля |
|---|---|---|
| _ChunkedCrossEntropy bwd | 732 | 40% |
| aten::mm (GEMM всего) | 674 | 37% |
| efficient-attention bwd | 193 | 11% |
| _ChunkedCE fwd | 139 | 8% |
| copy_/add_ | 312 | 17% (пересечения) |

Шаг eager ≈ 1.74 с; compile (уже включён в c8-конфиге) даёт −14%
на fwd+bwd (замер: 1634→1401ms).

## Попытки и честные вердикты

1. **Прямой LoRA-путь head-проекции** (без materialized [V,H]):
   118.8 → 128.6ms — РЕГРЕСС, откат. Материализация (1.7ms) не была
   узким местом; градиент effective-таблицы идёт в buffer без
   оптимизатора — autograd и так дёшев.
2. **Fused-CE + отдельный fp32 logsumexp для z-loss** (чтобы
   z_loss>0 не гнал в chunked): изолированный бенч 601 vs 732ms —
   победа; РЕАЛЬНЫЙ шаг 1742 → 1983ms — РЕГРЕСС, откат. Причина:
   fp32 logsumexp по [32736, 32768] на этой ROCm-сборке дороже
   fused-кернела CE; изолированный бенч с random W не воспроизвёл
   grad-путь LoRA-таблицы. Урок: изолированные бенчи HEAD-путей
   врать — мерить только полный train_step (Map ≠ Territory).

## Что осталось узким местом (для следующей попытки)

- ChunkedCE bwd 732ms: настоящий фикс — triton-кернел CE-backward
  (есть заготовка scripts/kernels/triton_ce_backward.py) с bf16
  z-loss в том же проходе, без fp32-материализации. Требует
  тщательной верификации чисел; очередь после рецензионных пунктов.
- compile уже включён; copy_ 1.32s self-CPU — H2D копии батчей
  (non_blocking отключён из-за HIP-гонки) — потенциально −0.1с/шаг
  при безопасном переиспользовании pinned-буфера; рискованно, отложено.

## Вердикт раунда

Скорость обучения НЕ изменена: обе «очевидные» оптимизации
измерены и отвергнуты (Kernighan: сначала измерь полный шаг).
Существующее состояние (compile on, chunked CE) — локальный
оптимум из дешёвых мер. Следующий шаг скорости — triton-CE-backward,
но он ниже по Gittins, чем рецензионные пункты 1–3 (scratch-контроль,
off-diag энергия, расширение гейта).
